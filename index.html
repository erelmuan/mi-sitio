¿Qué es el desarrollo web?

El desarrollo web consiste en crear sitios y aplicaciones que funcionan a través de un navegador.

Tecnologías principales

HTML

Se utiliza para definir la estructura y el contenido de una página web.

CSS

Permite modificar colores, tamaños, posiciones y estilos.

JavaScript

Permite agregar comportamiento e interactividad a una página.
